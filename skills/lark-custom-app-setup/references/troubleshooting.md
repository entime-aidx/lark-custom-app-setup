# 止まったとき

| 症状 | 確認と対応 |
|---|---|
| node/npm/claude/lark-cliが見つからない | 端末を開き直す。インストーラーのPATH案内と、使っているシェルを確認。環境全体を再導入しない |
| PowerShellでwhichやBash構文が動かない | 本手順はGit Bash用。Git Bashを開く。PowerShell専用に変更する場合は `Get-Command` 等へ置き換える |
| npm.ps1の実行が禁止 | 標準手順のGit Bashで確認。PowerShellからは許可されている場合に `npm.cmd` / `npx.cmd` を使えるが、会社の制限を解除しない |
| pluginコマンドが見つからない | 普通の端末ではなく `claude` 起動後の入力欄で実行する |
| gitがない／pluginを取得できない | Git導入とGitHubへの接続を確認。会社プロキシや配布方法に従う |
| Windowsでは動くがWSLでは見つからない | 別環境。Claude/Node/CLIを同じ側へ揃える。認証ファイルを安易にコピーしない |
| Larkの利用権限がない | ログイン中の会社、アプリの公開・承認・利用可能範囲を確認。Entime等の別会社アプリを流用しない |
| missing_scope / Permission denied | 必要scope、公開済みバージョン、本人のBase共有権限を確認。全権限追加・高度権限解除で回避しない |
| botでは空になる | アプリと本人は権限が違う。意図したuserプロフィールで確認し、認証の回避目的で身分を変えない |
| CLIは成功だが画面で編集できない | 所有者・共有先・アプリ名義/本人名義を確認。必要なら会社管理者が正しい共同編集権限を設定する |
| 認証期限切れ | 対象プロフィールを確認して本人が再認証。繰り返し失敗は原因を確認してから再試行 |
| 401/403/ダウンロード失敗 | 会社のネットワーク・プロキシ・公式配布元への通信を確認。TLS検証やセキュリティソフトを無効化しない |

困ったときに伝えるのは「OS・CPU・バージョン・止まった段階・秘密を除いたエラー」です。App Secretや認証URL全体は貼りません。
