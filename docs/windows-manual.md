# Windowsで始める Lark CLI 導入手順書

必要なソフトをまとめて導入し、Claude Codeから研修用のLark Baseに接続するための手順です。ZIPの手動ダウンロード・展開は不要です。

### この手順のゴール

① PCに必要なソフトがそろう → ② Claude CodeとLarkに本人のアカウントで接続する → ③ 研修用Baseで読み取り・書き込み・共同編集を確認する。

Lark CLIは、文字で指示してLarkを操作するための道具です。Claude Codeに研修用の案内機能を追加して、接続と操作を進めます。

### 始める前に準備するもの

- [ ] 会社でソフトの追加と外部AI利用が許可されたWindows PC

- [ ] インターネット接続とWinGet（アプリ インストーラー）

- [ ] Claude Codeを利用できる契約・アカウント、または会社指定のAPI利用環境

- [ ] 本人のLarkアカウントと、講師から案内する研修用BaseのURL

本手順は64bitのWindows 11、またはWindows 10 1809以降が対象候補です。会社が許可するサポート中のOSを使ってください。メモリは4GB以上、Node.jsは本研修では22以上を基準にします。

### 自動で入るもの／本人が行うこと

自動導入：Node.js LTS・Git・Claude Code・Lark CLI。導入済みのソフトは確認して再利用します。

本人の操作：導入の確認、必要な許可・利用規約の確認、Claude Codeへのログイン、研修用機能の追加、Larkの認証。会社のアプリ承認とBaseの共有設定は講師・管理者と進めます。

PCへの導入が終わっても、Larkの認証やBaseの編集権限はまだ確認できていません。最後のチェックまで進めてください。

## 1　必要なソフトをまとめて入れる

### ① Windows PowerShellを開く

Windowsのスタートメニューで「Windows PowerShell」を検索し、開きます。最初は通常の権限で開いてください。

### ② 開始ページのコードをまとめてコピーする

[開始ページを開く：PowerShellに貼るだけで開始](https://github.com/entime-aidx/lark-custom-app-setup/blob/main/docs/windows-quickstart.md)

ページ内の「& {」から最後の「}」まで、コードの枠全体をコピーします。コード枠のコピーアイコンが表示される場合は、それを使えます。タイトルや説明文は含めません。

Windows PowerShellに貼り付けてEnterを押します。複数行の貼り付け確認が出た場合は、開始ページからコピーした内容であることを確認します。

### ③ 導入予定を確認し、INSTALLを入力する

ダウンロードと内容の検査が終わると、導入予定が表示されます。内容を確認して、次の文字を半角の大文字で入力し、Enterを押します。

```text
INSTALL
```

必要なソフトが順番に導入されます。途中でWindowsの許可画面や利用規約が出た場合は、本人が内容を確認します。会社の管理者への確認が必要な場合は、ここで相談してください。

### ④ 完了表示を確認する

次の表示が出たら、PCへのソフト導入は完了です。

```text
PC SETUP COMPLETE.
Lark authorization and Base editing are NOT verified.
```

後半の英語は「Larkの認証とBase編集は未確認」という意味です。続いて、次の「Claude CodeとLarkを接続する」を行います。

### 途中で止まったら

赤いエラーや「Setup stopped」が出た場合は、最後の表示を記録して講師へ伝えます。実行制限を解除して続ける操作は行いません。詳しい対処は、このページ末尾の「症状に合わせて確認する」を参照してください。

## 2　Claude CodeとLarkを接続する

### ① 新しいGit Bashを開く

スタートメニューで「Git Bash」を検索して開きます。ここからはWindows PowerShellとは別の画面を使います。次を入力してEnterを押します。

```text
claude
```

案内に従ってブラウザで本人のClaude Codeアカウントにログインします。会社指定の利用環境がある場合は、その案内を優先してください。

### ② Claude Codeの入力欄で、2行を順番に実行する

以下はClaude Codeが起動した後の入力欄に入れます。Git BashやPowerShellの通常の入力欄には貼りません。1行ずつ入力し、それぞれEnterを押してください。

```text
/plugin marketplace add entime-aidx/lark-custom-app-setup
```

```text
/plugin install lark-custom-app-setup@entime-training
```

### ③ Claude Codeを開き直して、接続の案内を始める

追加が完了したらClaude Codeを終了し、新しいGit Bashで再び「claude」を実行します。Claude Codeの入力欄で、次の1行を入力してください。

```text
/lark-custom-app-setup:lark-custom-app-setup 研修用Base操作 Windowsで接続まで案内して
```

### ④ 講師の指定に従ってLarkを認証する

案内に従い、会社が用意・承認したLarkアプリと本人のLarkアカウントを使います。会社・アプリ・許可内容を確認して認証してください。アプリが未準備の場合は、各自で作成を始めず講師に伝えます。

App Secretなどの秘密情報は、講師が指定するローカルの設定画面で扱います。チャットやスクリーンショットに載せないでください。

「アプリの使用権限がありません」と表示された場合は、所属会社と利用可能ユーザーの設定を講師・会社管理者が確認します。別会社のアカウントに切り替えて解決したことにはしません。

研修ポータルのメールログインと、今回のLark CLI認証は別です。ポータルに入れても、CLIから操作できるとは限りません。

## 3　Baseで確認する・困ったとき

### ① 講師と一緒に、研修用Baseで動作を確認する

本番の業務データではなく、講師が指定したテスト用の表・項目を使います。Claude Codeへの依頼例：

```text
講師から指定された研修用Baseに接続できるか確認したいです。
まず読み取りだけを行い、書き込み前に対象と変更内容を見せてください。
```

- [ ] ブラウザで研修用Baseを開ける

- [ ] CLIから指定した表のデータを読み取れる

- [ ] 講師が対象と内容を確認後、テスト用の1行を追加できる

- [ ] 別の受講者が同じ行をブラウザで編集できる

- [ ] その変更をCLIから読み取り、反映を確認できる

すべて確認できたら「PC導入・Lark接続・Base共同編集まで確認済み」と講師へ伝えます。未完了があれば、止まった段階を伝えてください。

### ② 症状に合わせて確認する

WinGetがない：会社で許可された方法で「アプリ インストーラー」の導入・更新を管理者に依頼します。

スクリプトの実行が禁止されている：エラーを講師・情報システム担当へ見せます。実行ポリシーやセキュリティ設定を独断で変更しません。

古いNode.jsがある／途中で導入が失敗した：エラーを確認してから対処します。既に導入できたソフトは残ります。原因解消後の再実行では導入済みを再利用します。

claudeが見つからない／プラグインが出ない：新しいGit Bashで開き直します。プラグイン追加の2行が完了したかも確認します。

Larkに入れない／Baseを編集できない：本人の所属会社、アプリの利用許可、Baseの閲覧・編集権限をそれぞれ確認します。

問い合わせには「止まった手順番号・エラー全文・使用画面」を添えてください。パスワード、認証コード、App Secretは含めません。

### 講師・会社管理者の事前確認

代表のWindows PCで導入から共同編集まで試し、利用契約、Larkアプリの承認・利用可能者、研修用Baseの共有権限を整えます。企業ごとに共有先を確認し、他社の業務データを演習に混ぜません。

[詳しい接続・Base動作確認の手順（GitHub）](https://github.com/entime-aidx/lark-custom-app-setup/blob/main/skills/lark-custom-app-setup/references/verify.md)
