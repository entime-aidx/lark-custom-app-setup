# 講師向け：課題から共同編集まで

配布カリキュラムの単元と時間を優先します。このセットアップを理由に初日の全時間を環境構築へ置き換えません。

## 開始前

- Windows/Macの代表PCで導入・認証・演習Base共同編集まで確認する。
- 全員のOS、ソフト追加可否、Claude Code利用環境、Larkの所属会社を確認する。
- 会社が管理するアプリの利用方法、Secretの扱い、参加者の認証方法を決める。
- 実運用データと演習用Baseを区別し、編集してよい表を明示する。
- インストール不可の人には、Base画面での演習・ペア作業を用意する。

## 研修中

1. ポータルへ課題を1件共有する。今の管理表があれば共有可能な資料URLを添える。
2. 課題を「誰が・何を・どの頻度で・何に困っているか」に整理する。
3. 該当単元で、Baseの表・項目を設計する。
4. CLI準備済みの人は、承認された演習用Baseで構築・更新する。未準備の人は画面から操作する。
5. 別参加者が編集し、CLIと画面で同じ更新を確認する。
6. ポータルへ制作物URL・更新担当・試した結果・残課題を残す。

例：「案件の進捗確認に時間がかかる」→担当者/進捗/期限の表→共同更新→次回に確認回数や作業時間を振り返る。未測定の効果を削減実績として記載しない。

このリポジトリは導入と検収の教材です。ポータルから自動でBaseを構築する機能や、参加者権限を自動同期する機能は含みません。BaseのURLはポータルの制作物に紐付けます。生成物や業務データはこの公開リポジトリに保存しません。
